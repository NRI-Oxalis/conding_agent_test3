# 営業クロージング支援AIエージェント

Go言語とFyneフレームワークで作成されたGUIアプリケーションで、営業担当者のクロージングフェーズを支援します。契約情報の確認と社内規定に基づいた各種書類の自動生成を行います。

## 主要機能

### 🔍 契約情報確認支援
- 契約概要の入力・管理
- Confluenceからのルール取得と照合
- Mattermostからの過去事例検索
- 確認すべき情報リストの自動生成
- 注意点やヒントの提示

### 📝 書類自動生成支援
- 複数の書類タイプに対応（契約書、見積書、発注書等）
- Confluenceテンプレートからの自動生成
- テキスト形式でのプレビュー機能
- クリップボードコピー・ファイル保存機能

### ⚙️ API連携機能
- **Mattermost**: 過去の営業履歴から関連情報を検索
- **Jira**: プロジェクト・課題情報の取得
- **Confluence**: ルール・テンプレート情報の取得
- 安全な認証情報管理

## 技術仕様

- **開発言語**: Go 1.24+
- **GUIフレームワーク**: Fyne v2.4+
- **対象OS**: Windows（シングルバイナリ配布）
- **API連携**: REST API（Mattermost/Jira/Confluence）

## セットアップ・実行方法

### 必要条件

- Go 1.24以上
- Fyne依存関係（自動インストール）

### アプリケーションの起動

#### 開発環境での実行

```bash
# 依存関係のインストール
go mod tidy

# アプリケーションの起動
go run main.go
```

#### 本番用ビルド

```bash
# Windows用バイナリのビルド
GOOS=windows GOARCH=amd64 go build -o sales-closing-support.exe

# Linux用バイナリのビルド
go build -o sales-closing-support

# macOS用バイナリのビルド  
GOOS=darwin GOARCH=amd64 go build -o sales-closing-support-mac
```

### 初回設定

1. アプリケーションを起動
2. 「設定」タブを選択
3. API接続情報を入力：
   - **Mattermost**: サーバーURL、アクセストークン
   - **Jira**: サーバーURL、ユーザー名、パスワード
   - **Confluence**: サーバーURL、ユーザー名、パスワード
4. 「設定を保存」をクリック
5. 「接続テスト」で各システムとの疎通確認

## 使用方法

### 契約情報確認の実行

1. 「契約情報確認」タブを選択
2. 契約情報を入力：
   - 顧客名
   - 契約種別（新規契約/継続契約/追加契約/変更契約）
   - 製品/サービス名
   - 契約金額
   - 契約日
   - 営業担当者名
   - 備考
3. 「情報確認チェックを実行」をクリック
4. 確認結果とヒントを確認

### 書類生成の実行

1. 「書類生成」タブを選択
2. 書類情報を入力：
   - 書類種別（契約書/見積書/発注書等）
   - 顧客名
   - 製品/サービス名
   - 金額
   - 日付
3. 「書類を生成」をクリック
4. プレビューで内容を確認
5. 「クリップボードにコピー」または「ファイルに保存」

## API設定ガイド

### Mattermost API設定

1. Mattermostにログイン
2. **アカウント設定** > **セキュリティ** > **個人用アクセストークン**
3. 新しいトークンを作成
4. トークンをアプリケーションの設定に入力

### Jira API設定

1. Jira管理者に以下を依頼：
   - REST API アクセス権限
   - 適切なプロジェクト閲覧権限
2. ベーシック認証用のユーザー名・パスワードを設定

### Confluence API設定

1. Confluence管理者に以下を依頼：
   - REST API アクセス権限
   - 関連スペースの閲覧権限
2. ベーシック認証用のユーザー名・パスワードを設定

## セキュリティ

- API認証情報は暗号化されてローカルに保存
- 通信は全てHTTPS経由
- 機密情報のローカルファイル保存なし
- セッション管理による安全なAPI アクセス

## トラブルシューティング

### よくある問題

#### 「接続エラー」が発生する場合
- ネットワーク接続を確認
- API設定（URL、認証情報）を再確認
- 社内ファイアウォール設定を確認

#### 「書類生成に失敗」する場合
- Confluenceへのアクセス権限を確認
- テンプレートページの存在を確認
- 入力情報の形式を確認

#### アプリケーションが起動しない場合
- Go実行環境のバージョンを確認
- 依存関係を再インストール：`go mod tidy`
- ログファイルで詳細なエラーを確認
